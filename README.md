## Features

- Semantic document retrieval
- Conversational RAG workflows
- ChromaDB vector storage
- Ollama-powered local LLM workflows
- Context-aware memory retrieval
- Enterprise knowledge ingestion
- AI-assisted question answering
- Streamlit-based conversational UI

## Technology Stack

- Python
- Ollama
- ChromaDB
- Streamlit
- Vector Embeddings
- Semantic Search
- Retrieval-Augmented Generation (RAG)
- Local LLM Workflows

## Project Workflow

1. Upload enterprise documents
2. Parse and chunk content
3. Generate embeddings
4. Store vectors in ChromaDB
5. Perform semantic retrieval
6. Execute RAG-based prompting
7. Generate AI-assisted responses
8. Maintain conversational memory
9. Display results in Streamlit UI
